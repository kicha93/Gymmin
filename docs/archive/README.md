# Archiwum dokumentacji

Pliki w tym katalogu opisują usunięte systemy, dawne audyty albo zakończone refaktory. Nie są źródłem prawdy dla aktualnej aplikacji Gymmin.

Aktualny produkt jest mobile-only i local-only. Nie ma wspieranego backendu, kont, synchronizacji, Billing, kredytów AI ani zdalnego joba kreatora. Bieżąca dokumentacja jest indeksowana w [../README.md](../README.md).

Archiwum pozostaje w repozytorium wyłącznie jako zapis decyzji i pomoc przy kompatybilności historycznych danych. Poleceń wdrożeniowych, URL-i, modeli autoryzacji i checklist z tych plików nie wolno stosować do obecnego wydania.
