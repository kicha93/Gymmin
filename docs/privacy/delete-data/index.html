Usuwanie danych lokalnych Gymmin

Gymmin nie posiada konta ani serwera przechowującego dane treningowe. Dane usuwa się bezpośrednio na urządzeniu.

  1. Opcjonalnie utwórz kopię .gymmin.json w Ustawienia → Dane lokalne.
  2. Wybierz Ustawienia → Dane lokalne → Usuń wszystkie dane.
  3. Przeczytaj ostrzeżenie i zaakceptuj oba potwierdzenia.

Operacja usuwa lokalne treningi, historię, plan tygodnia, ustawienia, osiągnięcia, profil, avatar, przypomnienia i przejściowe dane AI. Jest nieodwracalna bez wcześniej utworzonej kopii.
