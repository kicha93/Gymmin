Deleting Gymmin local data

Gymmin has no account and no server storing workout data. Data is deleted directly on the device.

  1. Optionally create a .gymmin.json backup under Settings → Local data.
  2. Select Settings → Local data → Delete all data.
  3. Read the warning and accept both confirmations.

The operation deletes local workouts, history, weekly plan, settings, achievements, profile, avatar, reminders, and transient AI data. It cannot be undone without a previously created backup.
