Gymmin Privacy Policy

Last updated: August 11, 2026

Gymmin is an independent app created by Paweł Kaliszewski. Contact: kontakt@gymmin.app.

Local data

Workouts, sessions and history, all settings, weekly plan, favorites, reminders, achievements, local creator profiles, and the profile and avatar are stored only in the app's private storage. Gymmin requires no account, performs no cross-device sync, and has no server that stores these data.

AI

Gymmin prepares prompts locally and calls neither OpenAI nor any other AI API. The user chooses an external service and explicitly copies content to it; that service's privacy policy then applies.

Explicit external actions

Data can leave the app only after an explicit user action: creating an export or backup, pasting content into another app, or sending an email with the email client. Buy Me a Coffee and other explicit links open externally; Gymmin sends no data there and support grants no premium functionality.

Bug reports and contact

The form prepares a message locally and opens the system email app. The user reviews and sends the email to kontakt@gymmin.app. A report may contain the description, app and OS versions, platform, device model, language, current screen, and at most 10 safe diagnostic events. It excludes workouts, history, weights, creator profiles, AI prompts and responses, tokens, and former account identifiers.

Retention, deletion, and backups

Gymmin has no server copy of user data. Settings lets the user create a local .gymmin.json backup or irreversibly delete all Gymmin data, including avatar, reminders, and transient AI drafts. No separate data-deletion or account-deletion request is needed because Gymmin has no user accounts.
